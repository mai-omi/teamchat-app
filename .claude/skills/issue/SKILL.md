# Issue 起票スキル

## 目的

渡された機能の要望・実装単位を、**このアプリの設計書一式と食い違わないイシュー本文**に仕立てる。
受け入れ条件や画面・機能IDは設計書からそのまま引き、イシュー側で新しく作ったり言い換えたりしない。

---

## 入力

ユーザーから以下を受け取る（会話から読み取れる場合は確認不要）：

- **機能の要望、または実装単位の名前**：認証・チャンネル・メンバー管理・メッセージ・スレッド・検索・公開API のいずれか、または自由記述の要望
- **対応する Issue 番号**（分かれば）：本文末尾の `Closes #<番号>` に使う。無ければ空けておき、人に埋めてもらう

---

## 手順

### Step 1: 決めないといけないことが残っていないかを確かめる

渡された要望を読み、いまのコード（`routes/`・`app/`）と `docs/design/` の設計書一式を見て、
決めないといけないことが残っていないかを確かめる。

- その機能の受け入れ条件が `docs/design/acceptance.md` にすでにあるときは、**そこにある文言をそのまま写す**（言い換えない。設計書とイシューで文言を揃えるため）
- その機能に関わる確認事項が `docs/design/questions.md` に **回答なし／一部回答／保留** のまま残っているときは、イシューを起票せず、先にその旨を報告する（勝手に決めて埋めない）
- 実装単位と機能ID・画面IDの対応は `docs/design/acceptance.md` §0 の表（`features.md` の F-xx、`screens.md` の SC-xx）から引く

### Step 2: 関連する設計書を集める

実装単位に応じて、該当箇所だけを読む（全文は読まない）：

| 実装単位 | 見る設計書 |
|:--|:--|
| 認証 | `features.md`（F-01〜F-03）・`screens.md`（SC-01・SC-02） |
| チャンネル | `features.md`（F-04〜F-07）・`data.md`（channels テーブル）・`permissions-api.md` |
| メンバー管理 | `features.md`（F-08）・`permissions-api.md`（権限マトリクス） |
| メッセージ | `features.md`（F-09〜F-12）・`data.md`（messages テーブル）・`behavior.md` |
| スレッド | `features.md`（F-13）・`behavior.md` |
| 検索 | `features.md`（F-14） |
| 公開API | `features.md`（F-15・F-16）・`permissions-api.md`（§3 公開API） |

### Step 3: イシュー本文を組み立てる

出力形式（下記）に沿って本文を作る。受け入れ条件は `acceptance.md` にある行をそのまま使い、
無ければ「受け入れ条件が設計書にまだ無いため、先に `docs/design/acceptance.md` を埋める必要がある」と明記して止める（自分で作文しない）。

---

## 出力形式

```markdown
## 概要
<この Issue で実装する範囲を1〜3行。関係する F-xx／SC-xx を添える>

## 対応する設計書
- 機能: `docs/design/features.md` の F-xx
- 画面: `docs/design/screens.md` の SC-xx（該当する場合）
- データ: `docs/design/data.md` の該当テーブル（該当する場合）
- 権限・ルーティング: `docs/design/permissions-api.md`（該当する場合）

## 受け入れ条件
<`docs/design/acceptance.md` の AC-xx をそのまま転記。言い換えない>

## 確認事項
<関連する Q-xx が `docs/design/questions.md` にあれば状態を添えて列挙。無ければ「無し」>

Closes #<イシュー番号>
```

---

## 制約

- **コードは書かない**。イシュー本文の作成までが範囲
- 受け入れ条件を自分で作文しない。`docs/design/acceptance.md` に無いものは「無い」と報告し、先に設計書を埋めるよう促す
- `docs/design/questions.md` で未回答・保留の確認事項が関わる機能は、そのまま起票せず先に報告する
