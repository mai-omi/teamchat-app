# 機能一覧 ／ 今回作らないもの

`docs/spec.md`（仕様書）と `mockup/`（モックアップ）から、作る機能を洗い出したものです。
各行の「根拠」は、その機能がどこに書かれていたかを示します（spec = 仕様書の節番号、ファイル名 = モックアップの画面）。

---

## 機能一覧

| ID | 機能 | 何ができるか | 使える人 | 根拠 |
|:--|:--|:--|:--|:--|
| F-01 | 新規登録 | 表示名・メールアドレス・パスワードでアカウントを作る。入力ミス防止のため「パスワード（確認用）」の一致も確かめる | 未ログインの人 | spec 3-1 ／ `register.html` |
| F-02 | ログイン | メールアドレスとパスワードで認証する | 未ログインの人 | spec 3-1 ／ `login.html` |
| F-03 | ログアウト | ログイン中の状態を解除する | ログイン中の社員 | spec 3-1 ／ 上部バー（各画面） |
| F-04 | チャンネル作成 | 名前・説明・公開範囲（公開／プライベート）を決めて作る。作成者は自動でそのチャンネルのメンバーになる | ログイン中の社員 | spec 3-2・3-3 ／ `channel-new.html` |
| F-05 | チャンネル一覧表示 | 自分が見られるチャンネルを一覧とサイドバーに並べる。種類（公開／プライベート）・説明・作成者が分かる | ログイン中の社員 | spec 3-2 ／ `channels.html`・サイドバー |
| F-06 | チャンネル編集 | 名前と説明を直す（公開範囲はあとから変えられない） | そのチャンネルの作成者のみ | spec 3-2 ／ `channel-edit.html` |
| F-07 | チャンネル削除 | チャンネルと、その中のメッセージ・返信をまとめて消す。チャンネル名の入力で確認する | そのチャンネルの作成者のみ | spec 3-2 ／ `channel-edit.html` |
| F-08 | メンバー管理 | プライベートチャンネルのメンバーを追加・削除する。追加された人はその時点から読み書きできる。作成者は外せない | そのチャンネルの作成者のみ | spec 3-3 ／ `members.html` |
| F-09 | メッセージ一覧表示 | チャンネルのメッセージを古い順に並べる。投稿者・日時・日付の区切りが分かる | そのチャンネルを見られる社員 | spec 3-4 ／ `channel-show.html` |
| F-10 | メッセージ投稿 | その場で本文を書き込む（1,000文字まで） | そのチャンネルを見られる社員 | spec 3-4 ／ `channel-show.html` |
| F-11 | メッセージ編集 | 自分が書いたメッセージを直し、「編集済み」の印を付ける | 本人のみ | spec 3-4 ／ `channel-show.html`・design-guide §4 |
| F-12 | メッセージ削除 | 自分が書いたメッセージを消し、その場所に「このメッセージは削除されました」を残す | 本人のみ | spec 3-4 ／ design-guide §4 |
| F-13 | スレッド返信 | メッセージに返信を付け、元メッセージにぶら下げて読む。元メッセージには返信件数を出す | そのチャンネルを見られる社員 | spec 3-5 ／ `thread.html` |
| F-14 | メッセージ検索 | キーワードで、自分が見られるチャンネルのメッセージを探す。どのチャンネル・誰・いつが分かる。0件のときの表示もある | ログイン中の社員 | spec 3-6 ／ `search.html` |
| F-15 | 公開API：公開チャンネル一覧 | 未ログインで、公開チャンネルの一覧を読み取り専用で取得する | 未ログインを含む誰でも | spec 3-7 |
| F-16 | 公開API：公開チャンネルのメッセージ一覧 | 未ログインで、指定した公開チャンネルのメッセージを読み取り専用で取得する | 未ログインを含む誰でも | spec 3-7 |

### 全機能にかかる土台（個別機能ではないが必要なもの）

| 項目 | 内容 | 根拠 |
|:--|:--|:--|
| 権限・可視範囲の制御 | 公開／プライベートの可視範囲、作成者だけの操作、本人だけの編集・削除を、画面・API双方で守る | spec 2・3-2〜3-7 |
| 初期データ投入 | お披露目用に、アカウント3件・チャンネル4件・条件を満たすメッセージ群を最初から入れておく | spec 5-4 |
| 画面の体裁・状態表示 | 色・字・余白・状態（エラー・空・編集中・削除済み）を design-guide に合わせる | spec 5-3 ／ design-guide |

## 今回作らないもの（スコープ外）

仕様書 4章に挙がっているもの（理由は仕様書のまま）。

| 作らないもの | 根拠 |
|:--|:--|
| 新着メッセージの自動表示（開いたままで届く） | spec 4 |
| 通知（メール・スマホへの通知） | spec 4 |
| 1対1のダイレクトメッセージ | spec 4 |
| ファイル・画像の添付 | spec 4 |
| メッセージへのリアクション（絵文字） | spec 4 |
| 未読・既読の管理 | spec 4 |
| 管理者による全体管理（利用者の停止、他人のチャンネルの管理） | spec 4 |

仕様書に明記はないが、合わせて今回は作らないと考えているもの（念のため確認事項にも挙げています → `questions.md`）。

| 作らないもの | 根拠・理由 |

| パスワードの再設定・変更 | spec に記載がなく、今回の最小構成では見送る想定（Q-17） |
